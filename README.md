# 10-Tea-Business-Analytics
Power BI dashboard analyzing revenue, expenses, profit, and cost breakdown of a ₹10 tea business.
The Business Behind ₹10 Tea ☕

Power BI Business Analytics Project

Project Overview

This project analyzes the business performance of a tea shop selling tea at ₹10 per cup using Power BI.

Objectives

- Analyze revenue and expenses
- Understand profit performance
- Visualize daily sales trends
- Analyze fixed and variable costs
- Identify business insights

Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

Dashboard Highlights

- Revenue: ₹62.63K
- Total Expenses: ₹46.18K
- Net Profit: ₹16.45K
- Total Cups Sold: 6.3K
